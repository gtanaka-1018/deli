# エラビベースとの記事連携

更新日: 2026-09-10

億メーターの整備画面からエラビベースの実用記事を開ける。配達装備と雨具の手入れを共通表示し、バイクを選択した場合は車両比較を追加する。車両名に NMAX が含まれる場合は NMAX125 のスマホホルダー適合確認記事へ切り替える。車両名は表示の選択だけに使い、適合や購入の推奨を保証しない。

リンク先は公開記事の固定URLで管理する。記事の自動取得、埋め込み、外部画像の読み込みは行わない。新しいタブで開き、`noopener noreferrer` と `referrerpolicy="no-referrer"` を指定する。売上・資産・車両名・整備内容・利用者IDをURLや外部サイトへ送信しない。リンク先の記事には広告が含まれる場合がある旨を画面へ表示する。

## 相互案内

- 配達装備記事（WordPress投稿105）: https://erabibase.com/food-delivery-bike-gear/
- 車両比較記事（WordPress投稿40）: https://erabibase.com/nmax125-vs-pcx125/

両記事に売上・経費・車両ごとの整備履歴を記録する億メーターへの利用案内を追加する。保存先は使用中のブラウザーであること、別端末へ移る際は設定からバックアップまたは任意のクラウド同期を使うことを明記する。共通ログインやデータ同期を意味する連携ではない。

## 流入の確認

億メーターからの記事リンクは固定の `utm_source=okumeter`、`utm_medium=app`、`utm_campaign=delivery_support` と掲載位置だけの `utm_content` を付ける。記事からのリンクは `utm_source=erabibase`、`utm_medium=article`、同じcampaignと記事識別子（gear / bike_comparison）を付ける。

既存の Vercel Web Analytics の流入分類へ `erabibase` を追加する。分析用URLは `/referral/erabibase` に集約し、クエリとフラグメントを除去する。これは訪問の分類であり、記録開始や有料契約の成果測定ではない。共通の個人識別子や新しい追跡SDKは追加しない。

## 更新・取り消し

記事URLを変える際はHTTP 200と内容を確認する。表示コード変更後はService Workerのキャッシュ名を更新する。記事案内を戻す場合は、WordPress投稿の追加した見出し・説明・ボタン・保存先の説明だけを除去し、既存本文を保持する。億メーター側の案内と流入分類は該当コミットを取り消して再公開できる。保存データの形式は変更しない。
